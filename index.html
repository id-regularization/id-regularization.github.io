Motivation

A visually convincing match can still be the wrong person.

Many candidates can share the dominant description. Text-based person search still has to preserve the identity-level evidence that separates the true person from plausible look-alikes.

04 · IAPR's idea

Give each training identity a memory.

Observations can change from batch to batch while their identity-owned references remain available to future updates.

How IAPR works

Follow the training signal, not the equations.

Identity-Owned Prototype Memory

Keep multiple references for each identity.

Visual and textual prototype slots are owned by a training identity and updated from the observations assigned to them. Multiple slots let one identity retain more than one appearance or language mode.

The memory survives when the mini-batch is gone.
Memory updateAssigned observations update prototype memories with EMA.
No cross-ID assignmentOther identities cannot absorb a sample's prototype update.
Same-space comparisonCross-modal grouping is transferred, but targets stay in the supervised modality.
Auxiliary onlyThe original base objective remains active throughout training.

Why each component matters

Persistence alone is not enough.

Prototype memory by itself is mixed. Identity-restricted assignment makes the memory identity-aware, while same-space translated targets make cross-modal supervision modality-compatible. The full combination is the strongest configuration in the reported RDE ablation.

What changes in the retrieval space?

The correct identity gets more room to breathe.

IAPR does more than improve the final ranking. It changes the local competition between the best same-identity match and the strongest identity-wrong competitor.
