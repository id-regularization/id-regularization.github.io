Motivation

Matching the description is not the same as matching the identity.

Different people can share the same dominant visual cues. Text-based person search must still preserve the evidence that distinguishes the true identity from plausible look-alikes.

Remember each identity across batches.

Each training identity owns multiple visual and textual prototype slots. Identity-restricted assignment lets an observation select and update only the slots owned by its ground-truth identity.

Why each component matters

Persistence alone is not enough.

Prototype memory by itself is mixed. Identity-restricted assignment makes the memory identity-aware, while same-space translated targets make cross-modal supervision modality-compatible. The full combination is the strongest configuration in the reported RDE ablation.

What changes in the retrieval space?

The correct identity gets more room to breathe.

IAPR does more than improve the final ranking. It changes the local competition between the best same-identity match and the strongest identity-wrong competitor.
