Motivation

Matching the description is not the same as matching the identity.

Different people can share the same dominant visual cues. Text-based person search must still preserve the evidence that distinguishes the true identity from plausible look-alikes.

01 · Project

Attach at the final embeddings.

IAPR reads only the base retriever’s final image and text embeddings. Lightweight training-time heads map each modality into a normalized prototype space; the internal retriever architecture does not need to change.

One interfaceDifferent retrievers expose the same attachment point: their final visual and textual representations.
02 · Remember

Remember each identity across batches.

Each training identity owns multiple visual and textual prototype slots. Identity-restricted assignment lets an observation select and update only the slots owned by its ground-truth identity.

PersistentObservation-derived references survive the current mini-batch.
03 · Translate

Translate the grouping—not the feature vector.

Assignments from one modality define which paired embeddings are aggregated in the other modality. Structural information crosses modalities while the supervisory target stays in the feature space being regularized.

Same-space translationCross-modal structure moves; modality-specific feature spaces remain local.
04 · Regularize

Regularize the local identity competition.

Same-identity translated targets act as positives. IAPR selects the most similar identity-wrong references and concentrates the auxiliary loss on the strongest local competitors.

Local regularizationPull same-identity targets close; push the strongest identity-wrong targets away.

Training lifecycle

Warm up once. Regularize every active mini-batch.

The schedule has two phases—not four sequential stages. Epochs 1–5 train the base retriever alone; at epoch 6 IAPR is initialized, then its assign → update → compete → optimize cycle repeats for the rest of training.

What changes in the retrieval space?

The correct identity gets more room to breathe.

IAPR does more than improve the final ranking. It changes the local competition between the best same-identity match and the strongest identity-wrong competitor.
